المواصفات التقنية والمعمارية للمنظومة

🎯 معايير الأداء المعتمدة

  • الدقة المستهدفة (Target Accuracy): ≥ 98% على عينات الاختبار المتوازنة.
  • زمن الاستجابة (Target Latency): < 200ms (المحقق فعلياً: ~15-30ms).
  • النطاق المصنف: الأرقام العربية اللاتينية (1 إلى 9).

🧠 معمارية الشبكة والنموذج (Lightweight CNN & RF)

تستخدم المنظومة خط أنابيب هجين (Hybrid Pipeline) يجمع بين:

  • Lightweight CNN: شبكة التفافية خفيفة مدعومة بطبقات Batch Normalization و Dropout وتوسيع بيانات حركي (Data Augmentation) لمقاومة تدوير الخط وتشويش الكاميرا.
  • معالجة الصور الاستباقية: قص الإطار التلقائي (Bounding Box) وإعادة التوسيط لمركز الكتلة (Center of Mass) داخل إطار 28×28 بكسل لضمان مطابقة معيار MNIST.

🔒 الخصوصية والأمن والامتثال

  • معالجة في الذاكرة الحية (Ephemeral Memory): لا يتم حفظ صور الكاميرا أو اللوحة إلا إذا وافق المستخدم على إرسال تصحيح لتعلم النموذج.
  • RESTful API متوافق مع الحاويات: مزود بنقاط فحص الصحة /api/health وجاهز للنشر عبر Docker و Kubernetes.
